LEARN THE CONCEPT

How arrays power this app

An array stores several values of the same general kind under one variable name, with each value available by its index.

01

Store related values

Two arrays hold the class data: one for student names and one for their scores.

const names = ["Ama", "Kojo"];const scores = [90, 82];
02

Access by index

The same index connects a student to their score. JavaScript arrays start counting at index 0.

names[0] // "Ama"scores[0] // 90
03

Process with loops

Loops visit each score to calculate the total, average, highest, and lowest result.

average = total / scores.length;

WHY ARRAYS ARE USEFUL

Less repetition. Easier processing.

  • Keep related information organized.
  • Use loops to process many records.
  • Calculate summaries without separate variables for each student.
  • Make it easier to search, compare, and update values.
